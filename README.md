This repository contains the backend implementation for the Legal Lens project.

Legal Lens is a backend system built using FastAPI that answers legal questions using a Retrieval-Augmented Generation (RAG) approach powered by a Groq-based LLM.

# Legal Lens Backend

Legal Lens is a **Groq-based Legal Research and Reasoning Backend** built using **FastAPI**.  
It implements a clean **Retrieval-Augmented Generation (RAG)** pipeline to answer legal queries using structured legal documents.

This repository contains the **backend system** responsible for document ingestion, semantic search, and LLM-powered legal reasoning.

---

## 🚀 Features

- 🔐 **Auth API** (basic login placeholder)
- 🔎 **Semantic Search API** over legal documents
- 💬 **RAG-based Chat API** using Groq LLM
- 📄 Legal document ingestion and chunking
- 🧠 Local embeddings with sentence-transformers
- ⚡ In-memory caching for faster repeated queries
- 🧩 Clean service-based architecture

---

## 🏗️ Tech Stack

- **Backend Framework:** FastAPI
- **LLM Provider:** Groq
- **Embeddings:** SentenceTransformers (`all-MiniLM-L6-v2`)
- **Language:** Python 3.10+
- **API Docs:** OpenAPI (Swagger)
- **Version Control:** Git & GitHub
